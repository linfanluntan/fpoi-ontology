# W3ID registration for FPOI

Requested persistent namespace: `https://w3id.org/fpoi/`

Repository: `https://github.com/linfanluntan/fpoi-ontology`

GitHub Pages target: `https://linfanluntan.github.io/fpoi-ontology/`

## Registration steps
1. Enable GitHub Pages for the repository and verify the Pages target resolves.
2. Fork `https://github.com/perma-id/w3id.org`.
3. Add a new `fpoi/` directory containing this `.htaccess` and README.
4. Submit the pull request.
5. After merge, verify `https://w3id.org/fpoi/`, `/fpoi/1.0.1`, `/fpoi/ontology`, and `/fpoi/shapes`.

Do not claim W3ID dereferenceability before the upstream pull request is merged and these URLs resolve.
